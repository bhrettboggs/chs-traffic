# data/raw

| File | What | Source | Status |
|---|---|---|---|
| `scdot_aadt_2025_peninsula.csv` | 2025 Annual Average Daily Traffic (both directions combined) for ~66 SCDOT count stations on and around the Charleston peninsula | SCDOT "Average Daily Traffic for CHARLESTON County", 2025 PDF: https://www.scdot.org/content/dam/scdot-legacy/travel/pdf/trafficcounts/2025/CHARLESTON.pdf | **Transcribed by automated PDF text extraction. Spot-check every row against the PDF before relying on it.** The `role` column is a project label, not SCDOT data. |
| `chs_peninsula_drive.graphml` | OSM drivable street network | OpenStreetMap via Overpass (osmnx) | **Not yet downloaded** — run `python scripts/01_fetch_osm.py` |
| `chs_peninsula_edges.geojson` | Same network as GeoJSON for mapping | generated by script 01 | not yet generated |

Station numbers can be located on SCDOT's interactive count map (https://scdottrafficdata.drakewell.com/publicmultinodemap.asp), which also has hourly data for continuous-count stations. Station/route codes: `S-` = state secondary route, `L-` = local road, `SPR` = spur.
