# data/raw

| File | What | Source | Status |
|---|---|---|---|
| `scdot_aadt_2025_peninsula.csv` | 2025 Annual Average Daily Traffic (both directions combined) for ~66 SCDOT count stations on and around the Charleston peninsula | SCDOT "Average Daily Traffic for CHARLESTON County", 2025 PDF: https://www.scdot.org/content/dam/scdot-legacy/travel/pdf/trafficcounts/2025/CHARLESTON.pdf | **Transcribed by automated PDF text extraction. Spot-check every row against the PDF before relying on it.** The `role` column is a project label, not SCDOT data. |
| `chs_city_pavement_2024.geojson` | City of Charleston pavement inventory: 631 block sections (574 on the peninsula) with curb-to-curb width `CHSC_WIDTH` (ft), section name `PMS_SECTIO`, owner (City/SCDOT), functional class, survey year. Fetched 2026-11-09 for the bbox around the peninsula. | Charleston County GIS ArcGIS REST: https://gisccapps.charlestoncounty.org/arcgis/rest/services/Public_Works/Pavement_Condition_2024/MapServer/0 | `NUMBER_OF_` (lanes) seems to include parking lanes; not used. Joined to graph segments by `scripts/05_join_widths.py`. |
| `chs_peninsula_drive.graphml` | OSM drivable street network | OpenStreetMap via Overpass (osmnx) | Fetched 2026-11-09 (osmnx 2.1.1) |
| `chs_peninsula_edges.geojson` | Same network as GeoJSON for mapping | generated by script 01 | generated 2026-11-09 |

Station numbers can be located on SCDOT's interactive count map (https://scdottrafficdata.drakewell.com/publicmultinodemap.asp), which also has hourly data for continuous-count stations. Station/route codes: `S-` = state secondary route, `L-` = local road, `SPR` = spur.
